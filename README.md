# Grill Your Crumbs

An evidence-first interview demo that turns a rough career experience into specific resume material. The app asks focused follow-up questions, preserves what the user actually said, and shows where every generated segment came from.

Implementation and local setup instructions will be added with the first application commit.

## Prompt evaluation package

The WEWA-14 package in `docs/wewa-14-prompt-evaluation.md` contains three complete Grill for X question-selection prompts, a frozen implementation baseline, structured-output schema, dev/holdout eval sets, deterministic checks, and a reproducible comparison protocol.
