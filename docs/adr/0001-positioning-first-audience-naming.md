# 定位、首发人群、首发市场与定名

产品定位采用两层句式：Mission 层承诺「让对的人和机会找到你」（被动可发现），V1 产品层只承诺「把散落的、没用上的、没写清的经历问成拿得出手的个人资产——简历是第一个出口」。首发人群为中文实习/应届/1–3 年经验求职者（不限技术岗，含作品集/写作样本人群）；首发市场先中国大陆中文、后全球；定名双名制：Crumbs（英文/产品）+ 有料（中文传播）。第一购买理由是发现价值（「帮你找出没用上的、没写清的、散落的经历」），而非真实性防御或更快更好看的简历。

裁决于 2026-08-26，经创始人拷问会话确认（[Ticket #10](https://github.com/Taylorblue123/Grill-Your-Crumbs/issues/10)）。

## Considered Options

- 首发人群：全球 builder with side projects（Pitch.md 愿景人群）——判为愿景终局，非 V1 楔子；竞研证明求职 defend 场景购买动机更紧迫。
- 第一购买理由：「可 defend 的证据型简历」（竞研 §0.5 推荐）——创始人裁定降为支撑能力，发现价值为主承诺。
- 定位直接承诺「find opportunities and people」——被否：「find people」属 phase 2（本图 Out of scope），pitch 承诺 V1 不交付的东西；改为 Mission 层的「让机会找到你」。
- 定名单名（仅 Crumbs 或仅有料）、Lore、来电——被否，取双名。

## Consequences（架构性不变量）

1. **合规辖区与数据地域**：首发中国大陆 → PIPL 与《生成式 AI 服务管理暂行办法》适用，推理与存储优先境内；「先中国后全球」→ 架构自始预留双地域/双合规辖区与 i18n 扩展，不得硬编码单一地域假设。
2. **资产为中心，产出物为快照**：定位落点是「个人资产」，简历只是第一个出口。数据模型的中心实体是资产（经历/事实），不是简历文档。
3. **被动可发现性扩展点**：Mission 承诺「让对的人和机会找到你」→ 资产模型必须预留可见性分层与对外暴露的扩展点（phase 2），但 V1 一律私有。
4. **材料类型不限代码**：首发人群含作品集/写作样本人群 → 料（crumb）的类型系统自始按多模态材料设计（文本、repo、作品集、写作样本），不得只为代码/repo 建模。
5. **发现引擎是核心**：第一购买理由是「问出没写清的经历」→ 提问/挖掘引擎（发现材料无法重构的新信息）是产品核心能力；逐片段出处（provenance）保留为支撑性红线（见 PRODUCT.md），非第一卖点。
6. **双名品牌**：界面/代码用 Crumbs，中文传播用有料；文案系统自始区分品牌名的中英文语境。
